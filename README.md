# Karan Lodha — Portfolio

Bauhaus-inspired animated personal portfolio built with React + Vite + Framer Motion.

## Run Locally (VS Code)

```bash
# 1. Install dependencies
npm install

# 2. Start dev server
npm run dev
```

Opens at **http://localhost:5173**

## Build for Production

```bash
npm run build
```

Output goes to `dist/` — deploy to Netlify, Vercel, GitHub Pages, etc.

## Tech Stack

- React 19 + TypeScript
- Vite 7
- Framer Motion
- Tailwind CSS v4
- shadcn/ui components
- Wouter (routing)

## Features

- EN / DE language toggle
- Animated page loader
- Scroll-triggered section animations
- Contact form (opens mail client)
